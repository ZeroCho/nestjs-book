> 노드 내장 모듈은 40개가 넘습니다. 다 외우는 건 무의미해요.

## 1. 전역 객체 (require 없이 바로 쓰는 것)

### ✅ `console`

```js
console.log()      // 일반 출력
console.error()    // 에러 출력 (stderr로 나감 — 로그 분리 시 중요)
console.table()    // 배열·객체를 표로 (디버깅에 아주 유용)
console.time('t'); console.timeEnd('t');   // 실행 시간 측정
console.dir(obj, { depth: null })          // 중첩 객체 전부 펼쳐 보기
```

### ✅ `process`

```js
process.env.NODE_ENV       // 환경변수 (5-3강에서 사용)
process.argv               // 명령줄 인자 배열
process.cwd()              // 현재 작업 디렉터리
process.exit(0)            // 프로세스 종료
process.uptime()           // 실행된 시간(초)
process.memoryUsage()      // 메모리 사용량
process.nextTick(cb)       // 이벤트 루프에서 최우선 실행
process.on('SIGINT', cb)   // Ctrl+C 감지 (graceful shutdown)
```

`process.argv` 예시:

```js
// node app.js hello world
console.log(process.argv);
// ['/path/node', '/path/app.js', 'hello', 'world']
//   [0]=실행파일   [1]=스크립트    [2]부터가 실제 인자
```

### ✅ 타이머

```js
setTimeout(cb, ms)      // ms 후 한 번
setInterval(cb, ms)     // ms마다 반복
setImmediate(cb)        // 이벤트 루프 다음 턴에 즉시
clearTimeout(id) / clearInterval(id) / clearImmediate(id)
```

### ○ 기타 전역

| 객체 | 설명 |
|---|---|
| `global` | 브라우저의 `window`에 해당. 전역 객체 |
| `globalThis` | 환경 무관 전역 객체 (표준) |
| `__filename` / `__dirname` | 현재 파일 / 폴더 경로 (CJS 전용, ESM엔 없음) |
| `Buffer` | 바이너리 데이터 (1-3강) |
| `URL` / `URLSearchParams` | 주소 파싱 (2-1강) |
| `fetch` | 노드 18+에 내장. 별도 설치 불필요 |
| `structuredClone(obj)` | 깊은 복사 |
| `AbortController` | 요청 취소 |

## 2. 강의에서 쓴 모듈

| 모듈 | 쓴 곳 | 핵심 |
|---|---|---|
| ✅ `http` | 1-2, 2-1강 | `createServer`, `req`, `res` |
| ✅ `fs` | 1-3강 | `readFile`, `createReadStream`, `promises` API |
| ✅ `path` | 1-3강 | `join`, `resolve`, `extname`, `basename` |
| ✅ `crypto` | 5-3강 | 해시·암호화 (실무에선 bcrypt 사용) |
| ✅ `events` | 1-4강 | `EventEmitter` — 노드 전반의 기반 |

### fs의 세 가지 스타일

```js
// 1) 콜백 (전통)
const fs = require('fs');
fs.readFile('a.txt', (err, data) => {});

// 2) Promise (권장)
const fsp = require('fs').promises;
const data = await fsp.readFile('a.txt');

// 3) 동기 (서버에선 금지, 스크립트에선 OK)
const data = fs.readFileSync('a.txt');
```

### path 자주 쓰는 것

```js
path.join(__dirname, 'views', 'index.html')   // OS에 맞게 구분자 처리
path.resolve('a', 'b')                         // 절대 경로로
path.extname('photo.png')                      // '.png'
path.basename('/a/b/c.txt')                    // 'c.txt'
path.dirname('/a/b/c.txt')                     // '/a/b'
path.sep                                       // 윈도 '\', 그 외 '/'
```

> 윈도와 맥의 경로 구분자가 달라서 문자열 `+`로 경로를 만들면 한쪽에서 깨집니다.
> **경로는 항상 `path.join`으로.**

## 3. 알아두면 좋은 나머지 모듈

### ○ `os` — 시스템 정보

```js
const os = require('os');
os.cpus().length      // CPU 코어 수 ← pm2 클러스터에서 활용 (9-1강)
os.totalmem()         // 전체 메모리
os.freemem()          // 여유 메모리
os.homedir()          // 홈 디렉터리
os.platform()         // 'darwin' | 'win32' | 'linux'
os.hostname()
```

### ○ `url` — 주소 파싱

```js
const myUrl = new URL('https://a.com/path?q=노드#hash');
myUrl.protocol      // 'https:'
myUrl.hostname      // 'a.com'
myUrl.pathname      // '/path'
myUrl.searchParams.get('q')   // '노드'
```

### ○ `querystring` — 쿼리 문자열 (레거시)

`URLSearchParams`로 대체되었습니다. 옛날 코드에서 만나면 그때 찾아보세요.

### ○ `dns` — 도메인 조회

```js
const dns = require('dns').promises;
await dns.lookup('naver.com');       // OS의 호스트 해석 사용 (스레드 풀 사용)
await dns.resolve('naver.com', 'A'); // DNS 서버에 직접 질의
```

### ○ `util` — 잡다한 도구

```js
const util = require('util');

// 콜백 함수를 프로미스로 변환 (옛날 라이브러리 쓸 때 유용)
const sleep = util.promisify(setTimeout);
await sleep(1000);

util.inspect(obj, { depth: null, colors: true })   // 객체를 문자열로
util.deprecate(fn, '이 함수는 곧 사라집니다')
```

### ○ `zlib` — 압축

```js
const zlib = require('zlib');
fs.createReadStream('big.txt')
  .pipe(zlib.createGzip())
  .pipe(fs.createWriteStream('big.txt.gz'));
```

### ○ `stream` — 스트림 직접 만들기

1-3강에서 `createReadStream().pipe()`를 썼는데, 커스텀 스트림도 만들 수 있습니다.
`Readable`, `Writable`, `Transform`, `pipeline`.

```js
const { pipeline } = require('stream/promises');
await pipeline(readStream, transformStream, writeStream);   // 에러 처리까지 자동
```

### ○ `worker_threads` / `child_process`

→ **N-4 노트** 참고

### ○ `cluster`

→ **N-6 노트** 참고 (실무에선 pm2가 대신 해줍니다)

### ○ `readline` — 터미널 입력 받기

```js
const readline = require('readline/promises');
const rl = readline.createInterface({ input: process.stdin, output: process.stdout });
const answer = await rl.question('이름은? ');
rl.close();
```

CLI 도구 만들 때 씁니다.

### ○ `assert` / `test` — 테스트

노드 18+에는 **테스트 러너가 내장**되어 있습니다. Jest 없이도 됩니다.

```js
// test/sum.test.js
const test = require('node:test');
const assert = require('node:assert');

test('1 + 1 은 2', () => {
  assert.strictEqual(1 + 1, 2);
});
```

```bash
node --test
```

### ○ `perf_hooks` — 성능 측정

```js
const { performance } = require('perf_hooks');
const start = performance.now();
// ... 작업
console.log(`${performance.now() - start}ms`);
```

## 4. 모듈 이름 앞의 `node:` 는 뭔가요?

```js
const fs = require('fs');
const fs = require('node:fs');     // 같은 것
```

`node:` 접두사는 **"이건 확실히 내장 모듈"**이라는 표시입니다.
npm에 `fs`라는 이름의 패키지가 있을 수도 있으니, 헷갈림과 공격을 막아줍니다.
최근 코드에서 자주 보이니 알아두세요. 신규 코드에는 `node:`를 붙이는 걸 권장합니다.
