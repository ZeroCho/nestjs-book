8-3

스트리밍 채팅 (백엔드 + 프런트)

16분 · 라이브 코딩

ChatGPT처럼 글자가 흘러나오게. 1-3의 스트림이 여기서 부활한다.

8-3 · 개념

다 만들어 주기 vs 흘려 보내기

일반 — 몇 초 대기
const { text } =
  await generateText({ … });
res.json({ text });
// 완성될 때까지 침묵
스트리밍 — 글자가 흐른다
const result =
  streamText({ … });
return result
  .toDataStreamResponse();
// 조각조각 (SSE)
라이브 코딩

스트리밍 완성

  1. 백엔드: streamText + SSE로 응답 흘리기
  2. 프런트: 스트림 수신 후 타자 치듯 렌더링
  3. 세 모델에 같은 질문 → 속도·스타일 비교
결과 → 답변이 실시간으로 흐른다. “웹소켓 아니라 SSE — 응답은 서버→클라 한 방향이면 충분. 도구는 필요한 만큼만.”
1-3에선 디스크 → 브라우저로 흘려보냈고, 오늘은 AI가 만드는 글자를 흘려보낸다. 구조는 똑같다.

세션 관리·안정성·마무리

14분 · 라이브 코딩

대화를 기억하게 만들고 안정성을 강화해 앱을 완성한다.

라이브 코딩

기억하고 튼튼하게

  1. 대화 히스토리 저장 · 세션 분리 · MAX_HISTORY_LENGTH
  2. 입력 검증(파이프 회수) · 예외 필터 회수 · 타임아웃

결과 → AI 비서 앱 완성. “LLM은 기억력이 없어 매번 대화 전체를 다시 보낸다 — 3-2의 ‘서버는 방금 온 사람을 기억 못 한다’가 반복.”
